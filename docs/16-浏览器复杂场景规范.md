# 16 · 浏览器复杂场景规范（登录态 / 新标签页 / iframe / 视频播放）

> 来源：2026-11-14 gsmp AI学苑实测（登录态复用 → AI学苑新标签页 → 课程 → 7 节课 2x 播放 5s → 课时汇总）。
> 适用于：站内系统、SPA、iframe 嵌套、需要登录态、视频/播放器操作的插件。

## 一、登录态复用（首选）与过期回退

| 场景 | 做法 |
|---|---|
| 已有 storageState | `browser.newContext({ storageState: 'D:\\www\\dshspirder\\data\\sessions\\default.json' })`，免扫码 |
| 判断是否过期 | 打开目标页后检查 URL：含 `login.dingtalk.com` / `guard/sso` 即过期；或校验业务页特征元素 |
| 过期（人工介入） | 起**可见浏览器**打开入口 → 用户扫码 → `ctx.storageState({ path })` 保存；同时截二维码到文件备用 |
| 组织选择 | 钉钉登录前可能出现「请选择您所在的组织」，自动点目标组织（如「吉客印（郑州）数字科技」） |
| 失败语义 | 过期时任务 `failed`，错误写明"登录态已过期，请扫码更新 session 后重试"；**禁止**自动重试写操作 |

参考实现：`D:\www\dshspirder\gsmp-test\login-keeper.mjs`（可见窗口等待扫码 + 自动选组织 + 保存登录态）。

## 二、新标签页（window.open）

- 站内导航卡片常是 `window.open`：用 `context.on('page', p => ...)` 捕获新页，再 `p.waitForLoadState`。
- 更稳的做法：拿到目标 URL 后直接 `page.goto(目标URL)`（依赖登录态，不依赖点击）。
- 新页与主页面共享 context（登录态一致），无需二次登录。

## 三、iframe 嵌套

- 站点常把子系统放进 iframe（本次首页有 `gmater-ai/materialIndex`、`guard/workbench/hub`）。
- 遍历 `page.frames()` 找目标元素；跨 frame 点击用 frame 级 locator。
- 元素定位优先"文本 + role"，其次类名；选择器集中到 `SEL` 常量。

## 四、视频 / 播放器操作（重点）

```js
// 1) 等 video 就绪
const v = await page.evaluate(() => { const v = document.querySelector('video'); return v ? { ready: v.readyState, dur: v.duration } : null; });
// 2) 2 倍速播放 N 秒（浏览器要求 muted 才能自动播放）
const res = await page.evaluate(async (sec) => {
  const v = document.querySelector('video');
  v.muted = true; v.playbackRate = 2;
  await v.play();
  const t0 = v.currentTime;
  await new Promise((r) => setTimeout(r, sec * 1000));
  return { rate: v.playbackRate, t0, t1: v.currentTime, advanced: v.currentTime - t0, duration: v.duration };
}, 5);
// 3) 成功判据：advanced ≈ speed × sec（实测 2x×5s ≈ 9.9s）
```

注意：
- `duration` 可能异常（本次 11674s，疑似合集/HLS 聚合）→ 只作参考，不作真实时长；
- 播放会被浏览器自动播放策略拦截 → 必须 `muted=true` 后 `play()`；
- 记录 `readyState`、`currentSrc`、倍速，便于回溯；
- 若播放器是 iframe/第三方（腾讯/阿里播放器），需进 frame 或调用其 API。

## 五、SPA 状态污染（本次踩坑）

播放器打开后会覆盖课程列表 → 第二次点击 `.lesson-item` 元素虽在 DOM 中但被遮挡，`click` 超时。
**规则：每完成一个条目，重新 `goto` 列表页并重新进入详情，再点下一个**（代价是慢 30%，换来稳定）。
同理：弹窗/抽屉未关闭时，先 `Escape` 或点关闭，再继续。

## 六、等待策略

- 禁止固定 `sleep` 做"页面同步"；用 `waitForLoadState / waitForSelector / waitForFunction`。
- SPA 异步渲染可用"短轮询 + 上限"（如每 1.2s 检查 `video.readyState`，最多 30s），并记录等待耗时。
- 每次导航后 `networkidle` 兜底 + 1~2s 稳定期。

## 七、失败语义与继续执行

| 场景 | 处理 |
|---|---|
| 登录态过期 | failed，提示扫码；不重试 |
| 课程/课时找不到 | failed，写明"未找到 .lesson-item / 课程名" |
| 单节播放失败 | 记录 `status=failed` 与原因，继续下一节 |
| 连续失败 ≥3 | 停止剩余，输出部分结果 |
| 全部成功 | `done`，产物含逐条审计 |
