## 场景 4：本地台账坏数据（文件系统）

| 夹具 | bad.json / broken-schema.csv / notes.md / orders CSV / inventory.json |

| 证据 | `plugins/fs-ledger/service/data/jobs/20261115035317-8b4a/fs_ledger_dataset.json` |

## 结论

- 写操作必须有 dry_run + confirm_write，幂等键有效；模拟外部系统无重复写。
- 分页/瞬态失败重试有效，总行数与分页一致。
- 坏文件/缺列/不支持类型不被静默忽略，进入 `missingItems`。
- 报告与服务审计产物可回指 jobId/requestId。
