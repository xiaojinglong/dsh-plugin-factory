# 27 — M6 硬化与试点（A 单机版）

> 状态：M6 ~15%（控制面限流、health 就绪检查已实现；告警/备份恢复演练/容量/试点未完成）。

## 1. 已实现

- **POST 限流**：控制面按 IP 固定窗口（默认 120 次/分钟，`CONTROL_PLANE_RATE_LIMIT` 或 `createControlPlane({rateLimit})`），超限 429 + `Retry-After`。
- **health 就绪**：`GET /health` 返回 `checks.db`，DB 异常时 503；GET 不受限流影响。
- **错误处理**：统一 4xx/5xx 错误结构；5xx 记日志。
- **备份**：控制面 `POST /admin/backup` 已有；恢复演练未实现。
- **审计**：需求单/步骤/runner/accept 均有审计记录。
