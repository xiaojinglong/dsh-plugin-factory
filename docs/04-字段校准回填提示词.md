# 04 · 字段校准回填提示词（S5，关键新增）

> 为什么需要：SKILL.md 里最值钱的是**实测校准**（真实列名、脏值、勾稽关系），只有跑完执行层才知道。
> 用法：执行层真机跑通后，把本文件 + 产物信息发给 AI，让它只输出「需要替换的三节」。

---

## 输入

- 业务标识、业务中文名
- `taskId`
- 汇总表路径（`main.path`）、明细路径列表（`details[].path`、`itemName`）
- 现有 `SKILL.md`（初版·待实测校准）

## 动作（按序）

### 1. 读汇总表（`read_result_file(main.path)`）

提取并记录：
- **真实列名**：销售额列（`收入合计` / `订单合计` / `销售额` / 有效订单金额？）、毛利/成本/利润率列、占比列
- **剔除规则**：是否存在"合计/小计"行（如 `平台=合计`、站点名称为空）
- **合并单元格**：维度列是否只在组首行有值（平台/线路/团队/负责人）
- **特殊值**：`–∞`、空、`-`、`~`、0 分母
- **数据规模**：店铺行数、订单量合计

### 2. 读明细（`read_result_file(details[i].path)`）

提取并记录：
- **粒度**：订单级 / 产品级 / 单品级
- **首行是否汇总行**（订单号形如"有效订单量：N"）→ 分析前必须剔除
- **关联键**：与汇总表哪个字段对应（如【站点名称】）
- **可分析字段**：退款/头程/尾程/回扣/采购/佣金/广告/运营成本…
- **缺失字段**：哪些成本项恒为 0 或空（→ 口径风险，不是"没有成本"）
- **产品标识**：商品 ID 列表是否有金额拆分（没有就不能编"单品利润"）

### 3. 跑勾稽校验（必须给数字）

| 校验 | 期望 | 实际 | 结论 |
|---|---|---|---|
| Σ明细毛利（估） − 退损 = 汇总毛利润 | 误差 0.00 | | |
| 明细卖家订单额合计 = 汇总收入合计 | 一致 | | |
| Σ店铺毛利润 = 合计行毛利润 | 一致 | | |
| 净利润 vs（毛利润 − 运营成本） | 一致？ | | 不一致则标【待确认】 |
| 主键唯一（店铺/产品） | 唯一 | | |

> 本次实测示例：`Σ明细毛利（估） − 退损 = 汇总毛利` 逐笔吻合；但 4 家店 `净利润 ≠ 毛利润 − 运营成本`（差 14.15）→ 报表含未展示调整项，报告以净利润列为准 + 列待确认。

### 4. 输出三节（只输出这三节，供直接替换）

```markdown
### 4.5.x 字段校准（YYYY-MM-DD 实测）
- 汇总表实际列名：…
- 必须剔除：…
- 合并单元格处理：…
- 特殊值规则：…
- 明细结构：…
- 产品/订单级限制：…

### 4.5.y 口径核验
| 校验 | 结果 |
|---|---|
| … | ✅/❌ + 数字 |

### 10.x 待确认清单
| 事项 | 当前取值 | 影响 |
|---|---|---|
```

### 5. 同步更新（不新增章节，只补内容）

- **输出模板**：增加「数据口径」小节（任务 ID / 文件数 / 缺失清单 / 口径异常）
- **异常表**：补本次实测遇到的异常（如"直发订单佣金为 0 → 毛利率虚高，需标注"）
- **数据质量**：把"字段为 0 ≠ 真实为 0"写成显式规则
