# 技术演练记录：运营销售明细 Excel 汇总

> 这是技术演练，不是岗位用户验收。

## 目标

```text
输入：销售明细 Excel（区域、金额、订单号）
处理：按区域汇总
输出：区域、订单数、金额合计、占比
```

## 输入样例

```text
华东 1200 E001
华东 800  E002
华南 500  S001
华北 300  N001
华南 200  S002
```

## 结果

```text
总行数：5
区域数：3
金额合计：3000
```

| 区域 | 订单数 | 金额合计 | 占比 |
|---|---:|---:|---:|
| 华东 | 2 | 2000 | 66.67% |
| 华南 | 2 | 700 | 23.33% |
| 华北 | 1 | 300 | 10% |

输出：

```text
data/uat/pilot-sales-summary.xlsx
```

## 发现的问题

1. 沙箱对输出文件父目录的放行曾不完整，已修复并有回归测试。
2. 插件写输出前不要对已存在父目录做 `mkdirSync` / `existsSync`，否则需要额外读权限；输出目录存在时直接写。
3. ExcelJS 的 `writeBuffer` + `fs.writeFileSync` 比 `writeFile` 更适合沙箱。
