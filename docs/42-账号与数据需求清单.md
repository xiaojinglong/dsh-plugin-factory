# 42 — 账号与数据需求清单（按 Wave）

> 原则：**先 Wave 1 无账号插件，再按需接入账号**；账号只给最小权限，不给主密码。
> 不要把密码/token 直接贴在聊天里；用环境变量、DPAPI 或手动登录后的 storageState。

## 1. Wave 1：不需要账号（先做）

只需要样例导出文件（可脱敏）：

| 插件 | 需要的输入 | 文件格式 | 最少样本 |
|---|---|---|---|
| `git-flow-audit` | git log / PR/CI 导出 | JSON/CSV | 1 个仓库、3 个 Issue/PR |
| `boss-candidate-score` | 候选人导出 | CSV | 20 人（脱敏姓名/薪资可） |
| `product-selection-score` | 选品工具导出 + 趋势导出 | CSV | 3 关键词、10 ASIN |
| `ops-daily-audit` | 消息/订单/物流/Listing/广告导出 | CSV | 各 5–10 行 |
| `supplier-quote-compare` | 供应商报价 | CSV | 3–5 家 |

**你只需要提供脱敏 CSV/JSON**，不需要账号；这最适合先验证工厂的 CSV 映射、规则、报告和大数据量。

## 2. Wave 2：登录只读账号

| 平台 | 需要什么 | 权限 | 建议提供方式 | 风险控制 |
|---|---|---|---|---|
| BOSS 直聘 | 招聘者账号登录态 | 只读搜索/候选人卡片 | 你手动登录后导出 `storageState.json` | 只读、低频、人工复核；不群发 |
| 卖家中心 | 店铺只读 | 订单/消息/Listing 只读 | API key 优先；否则 storageState | 只读；不自动回复/改价 |
| 17TRACK | 查单 | 只读 API key | API key 环境变量 | 批量限速、失败降级 |
| Google Trends | 无需登录 | 只读 | 导出 CSV / SerpAPI key | 限流；失败用导出兜底 |
| 卖家精灵/Sorftime | 付费账号 | 只读导出 | CSV 导出优先；API key 次之 | 不共享主密码 |

### storageState 获取方式

1. 你在自己的浏览器手动登录目标站点；
2. 用 Playwright/浏览器插件导出 `storageState.json`；
3. 文件加密保存、加入 gitignore；给插件读取路径，不给账号密码。

> 如果平台没有导出能力，再讨论受控的浏览器登录方案；不要让插件保存明文密码。

## 3. Wave 3：写操作账号（最后，需明确授权）

| 平台 | 写操作 | 需要你确认 | 门禁 |
|---|---|---|---|
| BOSS | 批量打招呼 | 单次≤10 人、间隔≥30s、内容模板 | dry-run + confirm + 审计；建议只生成待发送列表 |
| 1688 | 询价/样品单 | 单笔/单日预算、供应商范围 | 人工确认 + 预算上限 + 逐条审计 |
| 卖家中心 | 回复消息/改 Listing/退款 | 可写范围、审批人 | dry-run + confirm + 额度 + 回滚 |

**建议**：Wave 3 先做“生成待发送内容 + 人工点发送”，不做全自动发送；等工厂写闸门/审计稳定后再放开。

## 4. 账号提供模板（复制填写）

```text
平台：
用途（只读/写）：
账号归属人：
授权范围（店铺/关键词/页面）：
有效期：
提供方式（环境变量/DPAPI/storageState/API key）：
禁止操作（如：不群发、不下单、不改价）：
审批人（写操作必填）：
```

## 5. 合规与数据

- BOSS 候选人姓名/截图属个人信息：限定招聘用途、保留期、脱敏；不进入公开报告。
- 1688 询价/样品涉及真实交易：必须人工确认与预算上限。
- 卖家中心写操作影响真实客户：必须 dry-run/confirm/审计/回滚。
- Google Trends/选品工具：遵守平台条款；优先导出/API，不高频爬取。
- 所有 token/密码：环境变量/DPAPI；仓库只保留 `.env.tmpl`，不提交真实 `.env`。

## 6. 建议推进顺序

1. **Wave 1（无需账号）**：先做 5 个 A 类插件，压工厂的 CSV/规则/报告/性能。
2. **Wave 2（只读）**：先选 1 个平台接入（建议 17TRACK 或 BOSS 只读），验证 storageState/限速。
3. **Wave 3（写）**：只做“草稿+人工确认”，不自动发送/下单。

## 7. 你回复什么即可

- “先做 Wave 1” → 我按 5 个插件排期/实现；
- “Wave 2 接 BOSS/17TRACK/卖家中心” → 按上面方式给 storageState/API key；
- “Wave 3 只做草稿” → 我按写操作门禁设计，不自动发送。
