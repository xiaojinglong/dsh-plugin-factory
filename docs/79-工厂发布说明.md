- portable 插件生成/校验/打包
- 标准安装、升级、回滚
- 异步 `create_plugin(wait:false)` / `finalize_plugin`
- 默认不自动验收
- 目标一致性运行时门禁
- 沙箱权限、密钥/凭证/网络审计
- 健康检查
- 岗位试点包、验收记录、发布模板

## 安装工厂

```powershell
git clone <repo>
cd dsh-plugin-factory
npm install
npm run control-plane
```

## 安装插件

```powershell
node scripts/dsh-factory.cjs install "<zip>" --profile desktop
```

升级/回滚：

```powershell
node scripts/dsh-factory.cjs install "<new-zip>" --profile desktop
node scripts/dsh-factory.cjs rollback <id> --dry-run
node scripts/dsh-factory.cjs rollback <id> --profile desktop
```

## 健康检查

```powershell
node scripts/factory-health.cjs --json
```

## 已知限制

1. **真实岗位试点尚未完成**：目前只有“销售区域汇总”技术演练，没有真实用户 3 次任务和签字。
2. **爬虫类目标一致性仍受外部页面/风控影响**：1688 10 页任务曾只完成 8–9 页，缺页会如实返回。
3. **ExcelJS 写文件在沙箱内需要输出父目录存在**；插件不应在写前对已存在父目录做 `mkdirSync`。
4. `finalize_plugin` 是新增 MCP 工具，升级后需要重启 DSH 才会出现在工具列表。
5. 当前是单机工厂，没有多用户/权限隔离/远程调度。


前 4 项已具备，真实岗位验收未完成，因此**不能标记为正式生产版**。

## 回滚

```text
回滚到上一个已安装版本：
node scripts/dsh-factory.cjs rollback <id> --profile desktop
```

回滚只改 profile 链接，不删除历史 zip；重启 DSH 生效。
