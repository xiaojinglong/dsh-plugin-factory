## 1.8 浏览器复杂场景实测（gsmp-academy，2026-11-14）

**执行层**：浏览器自动化（Playwright）。关键点与处理：

| 难点 | 处理 |
|---|---|
| 登录态过期（跳钉钉） | 用可见浏览器 `login-keeper.mjs` 等待扫码；自动选组织「吉客印（郑州）数字科技」后登录成功；`ctx.storageState()` 保存，后续免扫码 |
| AI学苑是新标签页（window.open） | 直接 `goto` 目标地址 `manage.giikin.com/fe/shop/wbw/video-learning`（共享 context 登录态） |
| iframe 嵌套 | 遍历 `page.frames()` 定位导航/元素 |
| 视频播放控制 | `video.muted=true; playbackRate=2; play()`；5 秒后 `currentTime` 前进 ≈9.9s 作为成功判据 |
| SPA 状态污染 | 播放器覆盖课程列表 → 第 2 节起点击超时；改为"每节重新进入课程页再点"，7/7 通过 |
| 登录态文件 | `data/sessions/default.json`（storageState），过期时任务 failed 并提示扫码 |
