# 销售区域汇总试点版

## 状态

```text
类型：内部技术试点插件
版本：0.1.0
安装位置：desktop profile
DSH 工具：sales_region_summary（已加载并调用）
真实岗位验收：未完成
```

## 插件

```text
包名：dsh-plugin-sales-region-summary
工具：sales_region_summary
```

## 使用方式

重启 DSH 后，直接说：

```text
把这份销售明细按区域汇总，输出订单数、金额合计和占比
```

或指定文件：

```text
汇总 D:\data\销售明细.xlsx，输出到 D:\data\区域汇总.xlsx
```

## 输入要求

Excel 第一张表：

```text
第 1 列：区域
第 2 列：金额
第 3 列：订单号
第 1 行：表头
```

空区域行会跳过；零金额区域保留。

## 输出

第一张表：

```text
区域
订单数
金额合计
占比(%)
```

## 内部样例

```text
data/uat/pilot-sample-1.xlsx
data/uat/pilot-sample-2.xlsx
data/uat/pilot-sample-3.xlsx
```

结果：

```text
data/uat/pilot-summary-1.xlsx
data/uat/pilot-summary-2.xlsx
data/uat/pilot-summary-3.xlsx
```

三份样例均通过，覆盖正常、空值/零金额、多区域。

## 限制

- 输出文件的父目录必须存在
- 只处理第一张工作表
- 只支持区域/金额/订单号三列
- 不处理合并单元格
- 这是内部技术试点，不是真实用户验收

用户样例
