# 31 — 依赖检查（M1）

> 目的：干净机/CI 上快速确认 Node、npm 依赖、Playwright 浏览器是否就绪；只读，不自动改动依赖。

## 用法

```powershell
npm run deps:check
# 或
node scripts/deps-check.cjs --fix   # --fix 只打印修复命令，不执行
```

输出 JSON：`ok`、`checks`（node/package-lock/模块/关键文件/Playwright chromium）、`fixes`。

## 修复命令（--fix 会打印）

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npx playwright install chromium
```

## 判读

- `module:@modelcontextprotocol/sdk` 等按 `node_modules/<mod>/package.json` 判断，避免 ESM exports 误报。
- Playwright 浏览器路径来自 `chromium.executablePath()`；不存在则 browser probe 会失败。
- 未做：自动安装依赖（需 owner/CI 环境决定）、npm 版本严格校验。

## 接入

- `npm test` 中包含 `deps.test.mjs`；CI 可单独运行 `npm run deps:check` 做快速失败。
- 安装器 `check` 仍独立检查 Node/deployment/patch；两者互补。
