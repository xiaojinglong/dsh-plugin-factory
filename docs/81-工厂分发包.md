# 工厂分发包

## 生成

```powershell
npm run factory:package
```

输出：

```text
release/dsh-plugin-factory-<version>.zip
release/dsh-plugin-factory-<version>.zip.sha256
```

包内容：

```text
apps/
packages/
platform/
scripts/
config/
docs/
deployment/
templates/
factory-kit/
catalog/
fixtures/
package.json
pnpm-lock.yaml
README / CHANGELOG / 设计文档
```

不包含：

```text
node_modules/
data/
.git/
release/
.dsh/
```

## 安装到新机器

```powershell
Expand-Archive release\dsh-plugin-factory-3.24.0.zip -DestinationPath D:\tools
cd D:\tools\dsh-plugin-factory
npm install
npm run control-plane
```

然后安装业务插件：

```powershell
node scripts/dsh-factory.cjs install "<zip>" --profile desktop
```

## 校验

```powershell
Get-FileHash release\dsh-plugin-factory-3.24.0.zip -Algorithm SHA256
```

当前包：

```text
文件：release/dsh-plugin-factory-3.24.0.zip
大小：521107 bytes
SHA-256：f6867a782466fd03b3d05b99631902732bc09101ddb641437ece605fbca90512
```

## 限制

- 不包含运行数据、登录态、任务结果、插件安装缓存
- 换机器迁移插件仍使用插件 zip，不复制 `AppData` 缓存
- 迁移说明见 [71-插件包位置与迁移.md](71-插件包位置与迁移.md)
