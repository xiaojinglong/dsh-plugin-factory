# 07 · 一页版 SOP（业务人员桌面版）

## 你现在要做什么

1. **写清业务**（5 分钟）
   - 要取什么数据（哪个系统/报表）
   - 要算什么指标、什么阈值算达标
   - 要产出什么报告、给谁看
   - 边界：只读 / 有写操作（写操作要审批）
   - 怎么算做对（抽查方式）

2. **发总控提示词**：把 `00-总控提示词.md` + 你的业务描述发给 AI，说：
   > 帮我做这个插件，业务标识 {可选}，产出 {什么报告}，只读。

3. **回答追问**（≤8 个/轮）
   - 不知道就说"按默认"，AI 会标注【默认，待确认】。

4. **扫码**（只在需要时）
   - 爬虫首次登录/登录失效时，AI 会给你二维码或链接，用钉钉扫一下即可。

5. **验收爬虫结果**
   - AI 会给你 3 次成功记录 + 文件路径；打开文件确认能看、列对。

6. **重启 DSH**
   - 完全退出（托盘退出）→ 重新打开 → 新建会话。

7. **会话首跑**
   - 说一句：「按 {业务标识} skill 做一次 {业务名}」→ 看报告。

8. **抽查签字**
   - 抽 1–2 个数字与页面核对，一致即通过。

---

## 你只需要做 3 个人工动作

| 动作 | 何时 |
|---|---|
| 扫码 | 首次登录 / 登录失效 |
| 重启 DSH | 配置改完后 |
| 抽查验收 | 报告出来后 |

其余全部由 AI 执行（建目录、写文档、写爬虫、改配置、冒烟、对账）。

---

## 卡住时对照

| 现象 | 你要做的 |
|---|---|
| 技能没出现 | 告诉 AI「技能没出现」，它会检查目录/命名/重启 |
| 工具没出现 | 告诉 AI「工具没出现」，它会检查 patch 配置 |
| 工具报错 | 告诉 AI「调用报错」，它会检查服务/端口/登录态 |
| 数字不对 | 先问 AI「数据口径是什么」，再看是不是筛选/周期问题 |
| 要等很久 | 正常（多店铺导出），不要重复提交 |
